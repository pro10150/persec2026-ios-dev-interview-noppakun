## โครงสร้างของ Repo
- ### bull-interview
    โปรเจกต์ Xcode Command Line สำหรับการแสดงผลทุกคำถามในที่เดียวเพื่อสามารถตรวจสอบได้ง่าย ใช้งานโดยการเปิดโปรเจกต์ bull-interview และรันผ่าน Xcode ใช้งานได้บน terminal
- ### Bracket
    แบบทดสอบข้อที่ 1 ตรวจสอบว่าสัญลักษณ์ครบคู่หรือไม่ สร้างเป็น Swift Package และมี Unit Test ในตัว
- ### StringSort
    แบบทดสอบข้อที่ 2 เรียงค่าที่รับเข้ามาให้ตรงตามโจทย์ สร้างเป็น Swift Package และมี Unit Test ในตัว
- ### Autocomplete
    แบบทดสอบข้อที่ 3 Autocomplete search สร้างเป็น Swift Package และมี Unit Test ในตัว
- ### ModernRomanNumerals
    แบบทดสอบข้อที่ 4 converไปมาระหว่างเลขโรมันและเลขอารบิก สร้างเป็น Swift Package และมี Unit Test ในตัว
- ### PositiveIntSort
    แบบทดสอบข้อที่ 5 sort เลข Integer ตามเลขแต่ละหลัก สร้างเป็น Swift Package และมี Unit Test ในตัว
- ### Tribonacci
    แบบทดสอบข้อที่ 6 สร้างเป็น Swift Package และมี Unit Test ในตัว
